# Machine Learning Projects – Elevvo Pathway Internship

This repository contains 5 machine learning projects covering regression,
classification and clustering.

## Projects

### 1. Student Score Prediction
Goal: Predict exam scores based on study hours.

Models:
- Linear Regression
- Ridge Regression
- Lasso Regression
- Polynomial Regression

Evaluation:
- R² Score
- Mean Squared Error

Results:
Polynomial Regression performed best with R² = 0.769.

---

## Mall Customer Segmentation

Goal: Segment mall customers based on income and spending behavior.

Methods:
- K-Means clustering
- Elbow Method for selecting optimal number of clusters
- DBSCAN clustering for density-based segmentation

Result:
K-Means identified 5 distinct customer segments representing different spending patterns.
